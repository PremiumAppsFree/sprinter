The first check downloads a free AI model once (about 300 MB; it is then kept on this device). Use Wi-Fi. On a phone it needs a recent phone with enough memory.

Good to know

  • This is a guess, not proof. The method scored very well in its author's own tests, but those used only about 200 AI images. It can be wrong, especially for edited, filtered, heavily compressed or very small pictures, screenshots, drawings and new AI apps.
  • It does not read Google's hidden SynthID watermark. Google's own SynthID check is in the Gemini app: upload the picture and ask “Was this made with Google AI?”.
  • Never accuse anyone based only on this result.

Method and probe weights: SynthID-detector (learned detector, MIT licence). Image features: OpenAI CLIP ViT-L/14 (MIT licence), ONNX version by Xenova on Hugging Face, run with ONNX Runtime Web.
