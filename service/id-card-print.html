Auto Print kya hai?

Auto Print se customer apne phone se shop ka QR scan karta hai, file upload karta hai, crop/preview check karta hai aur print job seedha aapke shop computer ki printer queue me aa jata hai. Shop PC me S Printer agent running rahe to print silently/direct nikal sakta hai.

Main kaam

1. Shop setup: Windows PC par agent install/verify hota hai aur printer select hota hai.

2. Customer QR: QR scan karke customer file bhejta hai; aapko phone se file lene ki zarurat kam hoti hai.

3. Payment/rate: Color/Gray rate, payment mode aur approval rule set karke controlled print flow chalta hai.

4. Print list: Paid, pending, approved, printed ya failed jobs ka record yahin dikhta hai.

1

Verify

Button pehle local agent check karta hai. Agent mil gaya to printer list load hogi aur download skip ho jayega.

2

Install

Agent missing ho to setup download hoga. Setup run karke Windows firewall/browser permission allow karein.

3

Start

Listener start hone par customer QR active hota hai aur new jobs shop printer tak aati hain.

Pehle verify, phir setup

Agar S Printer Auto Printer already installed aur running hai, download ki zarurat nahi. Verify & Setup button pehle local app check karega, phir website token software me save karega taki browser tab band hone par bhi auto print chale.

Setup me kya lagega?

1. Windows computer me shop printer already installed/working hona chahiye.

2. Setup file run karne ke baad local agent printer list aur queue handle karega.

3. Same button agent verify karke shop token, runtime key, API URL aur printer rule software me save karega.

4. Browser/firewall permission aaye to allow karein. Setup ke baad browser tab band ho sakta hai; bas computer aur software running hone chahiye.

Is button se kya hota hai?

Verify & Setup Auto Print ek hi button me 4 kaam karta hai: pehle installed agent check, phir zarurat ho to setup download, agent ready milte hi shop token save, aur background queue start. Rs 499 Auto Print subscription active nahi hai to isi action par subscription modal khulega.
