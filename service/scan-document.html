Tips for printer scans

Scan from printer works on Windows computers with the small S Printer scanner helper (one-time download). Without it, scan in HP Smart or Windows Scan at 300 dpi and add the JPG / PNG / PDF here.

A card or photo on the glass is cut out automatically. For a white card, put a dark sheet of paper over it before closing the lid, so its edges show.

Everything happens on this device. Nothing is uploaded.

Scan from your printer

Browsers can’t reach a scanner directly, so a small, free helper does it on this computer. You set it up once:

  1. Download the helperSPrinter-Scanner.cmd
  2. Open it. If Chrome asks, choose Keep; if Windows asks, choose More info → Run anyway. A small black window opens; leave it open (you can minimise it).
  3. Come back here. This window connects by itself. If Chrome asks to let this site use apps on your device, choose Allow.

Waiting for the helper…

The helper uses your normal Windows scanner driver, works only on this computer, and only answers the S Printer site. It is a plain text script, so you can open it in Notepad and read every line.

The printer’s scanner is reached through the Windows computer it is connected to (by USB or Wi-Fi). A phone browser can’t control it directly.

  • On this phone: use Scan with camera. It finds the page edges, straightens the page and cleans it like a scanner.
  • With the printer: open this page on the computer and press Scan from printer.
  • With the HP Smart app on the phone: scan there, save the file, and add it here with From scanner, gallery or PDF.
